# About me

- 👋 Hi, I’m jykim74 and I am korean (I am not good at english. I need to learn english more. )
- 👀 I’m interested in PKI programs and I have developed these programs with Openssl3 and QT.
- 🌱 [The BerEditor](https://jykim74.github.io/wiki/bereditor) is a tool for decoding and encoding BER and DER.
- 💞️ [The CertMan](https://jykim74.github.io/wiki/certman) is a tool for managing X.509 Certificate and CRL.
- ✨ [The CryptokiMan](https://jykim74.github.io/wiki/cryptokiman) is a tool for managing HSM device with cryptoki library.
- 📫 The PKILib is not public.( I have not plan to publish the library yet. )

This program is a management program that generates X.509 certificates, CRLs, CSRs and key pairs.

Supported algorithms are RSA and ECDSA algorithms. The file can be downloaded from this page link (size is about 30M) This is a program I made personally, so if you have any questions or bugs, please Use Google Groups
